Discrete Mathematics Formulas Used

1. Shannon Entropy (Theoretical Information Limit)
H(X) = - ∑ p(x) × log2(p(x))
Measures the fundamental uncertainty or average information content produced by the source. Claude Shannon's source coding theorem proves that no lossless compression scheme can have an average length smaller than H(X).
2. Average Code Length (L)
L = ∑ p(x) × length(code(x)) = (Total Compressed Bits) / (Total Characters)
The expected number of bits required to encode one symbol. Huffman coding is mathematically proven to minimize L for any prefix code.
3. Coding Efficiency (η)
η = ( H(X) / L ) × 100%
The ratio of theoretical minimum entropy to actual average code length. The closer η is to 100%, the closer the algorithm is to optimal compact coding.
4. Kraft-McMillan Inequality
K = ∑ 2-li ≤ 1.0
A fundamental theorem in discrete mathematics: A uniquely decodable code with binary codeword lengths l1, ..., ln exists if and only if Kraft's sum does not exceed 1.
5. Redundancy (R)
R = L - H(X) ≥ 0
The excess bits used per symbol beyond the minimum entropy limit.

Data Structures Used in the Algorithms

Huffman Coding Data Structures

Priority Queue / Min-Heap: Stores tree nodes sorted by frequency. In each step, the two nodes with minimum frequencies are popped in O(log N) time, merged into a new composite node, and pushed back. Total tree construction time: O(N log N).

Binary Tree (Trie): The final root node represents the entire source alphabet. Traversing left gives '0', traversing right gives '1'. Leaf nodes store individual source characters.

Ordered Map / Hash Table: Fast O(1) codeword lookup table during encoding.

Shannon-Fano Coding Data Structures

Sorted Array: Characters are initially sorted in descending order of their probabilities in O(N log N).

Recursive Divide-and-Conquer: The sorted list is partitioned into two subsets at an index k that minimizes |∑left p - ∑right p|. Symbols in the left subset receive a '0' bit; symbols in the right subset receive a '1' bit. Continues recursively until subsets have size 1.

Streaming Decoding Engine

Instantaneous Prefix Tree Walker: Because both Huffman and Shannon-Fano are prefix-free, an incoming bitstream is decoded deterministically by walking down the tree from the root with each bit. When a leaf is reached, the character is emitted immediately and the traversal resets to the root in O(1) space without lookahead.
